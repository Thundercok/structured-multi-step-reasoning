# RAT Lite: focused interaction overhaul, 2026-10-30

User narrowed Lite to finding files and translating text, and requested an overhaul of startup, input and results. The current change presents setup and the composer in a centred rectangular window, opens the composer after setup and on ordinary launch, labels the one input for the two tasks, and simplifies the secondary menus. Existing organization recovery remains accessible so prior journaled operations can still be undone. The older organization and source-analysis capabilities are still registered internally; removing or migrating them is not claimed here.

The setup screen allows typed translation and file finding without Accessibility; selected-text access still requires trust for the running bundle. A QML visibility/height cycle was reproduced as a one-pixel window and repaired. In the source app the real UI displayed setup, translated a public sentence, found project_scope.md and invoked its open operation. Source execution did not have the packaged hotkey helper. Packaged-app acceptance, physical shortcut capture and a live model-driven Agent loop remain unverified. Stage 0 and main-app integration remain unchanged.
