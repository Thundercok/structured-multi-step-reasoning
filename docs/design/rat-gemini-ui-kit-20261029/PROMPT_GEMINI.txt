Design a new visual concept for FULL RAT, a desktop AI reasoning assistant. Use the attached images according to the roles below. Generate UI concept images, not code or a website.

PRODUCT
RAT helps users work with information and computer tasks through structured reasoning and tool-assisted execution: understand a request, choose tools, execute steps, inspect evidence, verify results, and ask for clarification or stop when appropriate. Its product scope includes finding files/apps, reading documents and extracting text, translation, calculations, answer checking, and previewing file organization before explicit Apply/Undo. This is the full product direction, not a claim that every capability already works. It is not a pomodoro app, game, generic chatbot website, or merely a translation utility.

ART DIRECTION
The UI is professional, calm, coherent, readable and restrained.
The rat is warm, awkward, mischievous, deadpan and slightly shitpost-like.
Its default expression is wide-eyed and apparently brain-empty. Its occasional gremlin/cursed reactions come from posture and eye direction, not redesign.
It looks absurd but treats the user's work attentively. Never contemptuous toward the user.
Preserve the irregular black outlines, oversized uneven eyes, long muzzle, irregular ears, sparse whiskers, gray-brown body, tiny hands, pink feet and thick pink tail.
No polished corporate mascot, symmetric cute mouse, realistic fur, 3D, new costumes, or generic anime styling.

UI REQUIREMENTS
- A compact floating macOS desktop assistant with a readable expanded workbench when content needs room.
- Exactly one natural-language input and one send button. No mandatory mode tabs or file/translate selector before typing. The assistant routes requests.
- Give the mascot a deliberate place beside the interface. Keep pose scale and anchoring stable as content changes; speech bubbles should not jump unpredictably.
- Make long content readable through deliberate expansion/scrolling, without giant empty panels or tiny text.
- Show concise actual task status, useful results, source references and verification summaries. Do not display raw private chain-of-thought, debug logs, or made-up success/progress as a product feature.
- File results need filename, location/type and clear open/read actions.
- Document reading needs document/page context, source excerpt and room for a follow-up question.
- File-organization concepts, if explored later, need a preview and explicit Apply/Undo rather than an automatic destructive action.
- Support waiting, processing, needs-input, result, empty and recoverable-error states with the same visual language. Show success only after confirmed completion.
- Keep technical details behind a secondary disclosure when useful.
- Use Vietnamese UI copy, short and natural. Prioritize readable typography over decorative lettering.

THEMES
Create a light and dark version with EXACTLY the same content, geometry, hierarchy, mascot pose/position and component sizes.
Light: warm off-white and neutral surfaces, muted sage accent, charcoal text; restrained dusty-pink details may echo the rat.
Dark: warm charcoal surfaces, readable off-white text and restrained sage accents. Keep the mascot's dark outlines distinguishable.
These colors are a starting direction from the supplied images, not a demand to repeat every existing olive-tinted surface.
Avoid neon, gaming HUDs, excessive glass/gradients, large nav sidebars, dashboard charts and landing-page hero layouts.
